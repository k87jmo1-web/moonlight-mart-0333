# 03:33 — 야간수당

평범한 편의점 알바가 은하계 보급소의 오배송 사고를 수습하는 짧은 2D 액션 RPG입니다. 서버·빌드·외부 에셋·패키지 설치 없이 동작합니다.

## 바로 실행

`index.html`을 브라우저에서 열면 플레이할 수 있습니다. 자동 저장의 안정성을 위해 로컬 HTTP 실행을 권장합니다.

```powershell
cd D:\game
python -m http.server 8765 --bind 127.0.0.1
```

브라우저에서 http://127.0.0.1:8765 를 엽니다. 동일한 주소·브라우저에서 저장이 유지됩니다. 파일 직접 실행의 localStorage 지원은 브라우저 설정에 따라 달라질 수 있습니다.

## 조작

| 키 | 동작 |
| --- | --- |
| WASD / 방향키 | 이동 |
| 마우스 이동 + 왼쪽 버튼 유지 | 조준 / 연사 |
| J 유지 | 가까운 적 자동 조준 공격 |
| Space | 무적 회피 (재사용 1.25초) |
| E | 출입문, 보급품, 드롭 무기, 계산대 |
| Q | 삼각김밥 사용 (최대 HP 55% 회복) |
| I | 가방 / 무기 비교 / 장착 / 분해 |
| R | 3초 귀환, 피격 시 취소 |
| Esc | 일시정지 |

모바일에서는 화면 방향키와 회피·E 버튼을 사용하며 가까운 적을 자동 공격합니다. 장비와 귀환은 옆 패널에서 사용합니다. 데스크톱 플레이를 우선으로 설계했습니다.

## 진행과 파밍

- 편의점: 무료 HP 회복, 김밥 구매, 영구 체력·공격·이동 강화.
- 골목 → 누적 6킬 → 뒤집힌 주차장 → 누적 16킬 → 본사 물류 균열.
- 각 구역의 1회 보급 상자, 몬스터의 무기 드롭, 엘리트의 확정 드롭.
- 무기 5종: 연사 권총, 범위 폭발 캐논, 관통 레이저, 광선검, 4연쇄 테슬라.
- 희귀도 4단계 + MK 등급 + 무기 강화 +0~+3. 가방은 24칸입니다.
- 바닥 무기와 상자는 가까이에서 **E 한 번으로 즉시 획득**합니다. 획득 팝업이나 자동 장착은 없습니다. 가방이 가득 차면 무기/상자는 그대로 남습니다.
- **I → 무기 슬롯 클릭**으로 상세 비교, 장착, 분해를 합니다. 목록에는 아이콘·이름·등급·강화만 간단히 표시합니다.
- 장착 중인 무기는 분해 불가. 다른 무기는 상세 화면에서 분해를 확인하면 돈 대신 **잔류 전지**를 받습니다.
- 레벨당 HP +15, 공격 배율 +7.5%, 체력 40 회복. 상점 강화는 각 8단계.
- 사망 시 돈 15%만 차감하고 거점 부활. 장비·경험치·강화 보존.
- 보스 처치 시 엔딩과 전설 테슬라 보상. 이후 자유 탐험 가능.

8초마다, 획득·분해·강화·승급·구매·장비 교체·귀환·창 전환 시 localStorage에 자동 저장합니다. 다시 접속하면 편의점에서 시작합니다. 적과 드롭은 구역을 떠날 때 초기화됩니다. Esc → 새 근무 기록에서 초기화할 수 있습니다.

## 잔류 전지와 무기 성장

잔류 전지는 잘못 배송된 차원 병기에 남은 에너지입니다. 몬스터 처치(3킬마다 보장 및 추가 확률), 엘리트, 탐험 상자(8/11/14개), 보스(30개), 무기 분해로 얻습니다. 획득한 재료는 자동 정산되며 사망해도 유지됩니다.

- 편의점에서 **I → 무기 선택**, 또는 계산대 **E → 무기 관리**로 강화합니다. 밖에서는 비교·장착·분해만 가능합니다.
- +1마다 피해 배율 +12% (최대 +3에서 ×1.36). 블래스터와 광선검은 공격 속도 배율도 단계당 +2% 증가합니다.
- +3 무기는 **일반 → 희귀 → 영웅 → 전설**로 승급할 수 있습니다. 기존 희귀도 배율(1 / 1.3 / 1.65 / 2.1)을 적용하며 +3과 MK 등급은 유지합니다.
- 강화·승급은 실패나 파괴 없이 확정입니다. 구매 전에 다음 공격력과 비용을 표시합니다.
- 무기 분해 시 `3 + 희귀도 인덱스×4 + (MK−1) + 강화 단계×2`개의 전지를 얻습니다.
- 강화 비용: 돈 `35 + 현재 강화×30 + 희귀도 인덱스×20`, 전지 `3 + 현재 강화×2 + 희귀도 인덱스×2`.
- 승급 비용: 돈 `90 + 현재 희귀도 인덱스×130`, 전지 `8 + 현재 희귀도 인덱스×8`.
- 일반 +0을 일반 +3, 희귀 +3까지 키우는 총비용은 **₩285 + 전지 23개**입니다.
- 일반 드롭 중 전설 비율은 구역별 약 0.7% / 1.1% / 1.5%, 영웅은 5% / 6.5% / 8%입니다. 엘리트와 후반 상자는 최소 희귀, 보스의 전설 보상은 유지됩니다.
- 보스 보상은 가방이 가득 차도 임시 초과 수납해 기존 무기를 지우지 않습니다. 분해해 빈칸을 만들면 다시 주울 수 있습니다.

기존 v1 저장 키를 유지합니다. 이전 무기에는 +0, 재료에는 0을 적용하고, 기존 레벨·돈·장비·강화·진행을 보존합니다. 예전 획득 창에 남아 있던 무기도 자동 수납합니다. v1 원본은 같은 브라우저에 `moonlight-shift-v1-backup-v1` 키로 1회 보관합니다.

## GitHub Pages 배포

1. GitHub 저장소를 만들고 `index.html`, `style.css`, `game.js`, `gear.js`, `.nojekyll`을 루트에 업로드합니다. README와 tests는 선택입니다.
2. 저장소 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택합니다.
3. 업로드한 브랜치(보통 `main`), 폴더 `/ (root)`를 선택하고 Save합니다.
4. 배포가 끝나면 표시되는 `https://사용자명.github.io/저장소명/` 링크를 공유합니다.

상대 경로만 사용하므로 저장소 하위 경로에서도 동작합니다. 백엔드, API 키, 환경 변수, npm install은 필요 없습니다. 저장은 각 플레이어의 브라우저에만 남으며 계정 간 동기화는 없습니다.

## 파일과 검사

- `index.html`: 게임 화면과 상태 패널
- `style.css`: 반응형 UI
- `game.js`: 전투, 게임 데이터, 저장, Canvas 렌더링
- `gear.js`: 장비 UI, 무기 아이콘, 분해, 강화, 등급 상승
- `tests/game.test.cjs`: 전투·성장·저장·상점·부활·보스 회귀 테스트
- `tests/browser.html`: 실제 DOM과 Canvas에서 획득부터 재접속까지 검증하는 브라우저 통합 검사. 테스트용 전용 저장 키와 고정 전투/자원 조건을 사용하며 실제 세이브를 변경하지 않습니다. HTTP 실행 후 이 파일을 열어 검사를 실행합니다.

```powershell
node --check game.js
node --check gear.js
node --test tests/game.test.cjs
```

향후 추가 후보: 무기별 고유 픽셀 아트, 이상한 손님 의뢰, 추가 보스 패턴, 세이브 내보내기. 현재 버전은 짧은 1회차 완주를 우선한 MVP입니다.
